## 🧩 About

**World War 3 Companion** is a curated list of World War 3 open-source tools:

- **Overlays** — on-screen helpers, layout notes, minimap viewer, loadout switcher
- **Quality-of-Life Helpers** — weapon catalog, attachment manager, overlay notes
- **Research Notes** — practice layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

## ✨ Features

### ESP
- Loadout Switcher — practice from any saved preset
- Show Hitboxes — visualize damage hitboxes
- Replay Notes — record and review match runs
- Playback Speed — adjust replay playback for study (0.1x to 5x)

### Wallhack
- Weapon Catalog — browse weapons, skins, camos, attachments
- Custom Loadout Notes — organize player equipment
- Marker Visibility — improved teammate and objective markers

### Aimbot
- Practice Mode Notes — segment study on any map layout
- Stance Control Notes — review crouch and prone transitions
- Recoil Buffer Notes — chain complex aim patterns in the range
